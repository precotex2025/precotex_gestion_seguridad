# Reglas Obligatorias del Proyecto Precotex

## 1. Consulta y Aplicación Activa de Skills
En cada solicitud del usuario referente a desarrollo, maquetación, correcciones o mejoras:
- Consultar y aplicar los lineamientos de las **Skills Instaladas** documentadas en [src/ReglasSklills/Skills.md](file:///d:/Fuentes_Preco$/precotex_gestion_seguridad/precotex_gestion_seguridad/precotex_gestion_seguridad/src/ReglasSklills/Skills.md) y en el sistema Antigravity.
- Utilizar activamente:
  - **`frontend-design` & `theme-factory`**: Para diseño UI/UX empresarial moderno, limpio, paletas claras acordes al layout blanco (*Light Enterprise*), tipografías nítidas, contrastes adecuados, microinteracciones y componentes consistentes.
  - **`webapp-testing`**: Para validar y probar componentes web y flujos en navegador cuando se requiera.
  - **`xlsx`, `docx`, `pdf`, `pptx`**: Para cualquier generación, formateo y exportación de reportes de calidad ejecutiva.
  - **`mcp-builder` & `doc-coauthoring`**: Para conectores con bases de datos y documentación técnica de arquitectura.

## 2. Estándares Visuales y UI/UX
- **Tema Claro Coherente**: Toda la interfaz (modales, tablas, tarjetas, gráficos) debe estar perfectamente integrada al fondo blanco/claro del sistema Precotex, evitando contrastes oscuros fuera de lugar.
- **Gráficos y Métricas**: Usar colores corporativos armónicos (índigo `#4f46e5`, verde `#10b981`, ámbar `#f59e0b`, rojo `#ef4444`, texto oscuro `#0f172a`, bordes suaves `#e2e8f0`).
- **Calidad de Código**: Mantener TypeScript y Angular actualizados, sin errores en consola y con validaciones completas.
